## Why

The landing's Rewards value section still uses oversized cards, generic decorative metrics and competing actions. After the coupon and learning previews, visitors need a compact reason to join rather than another catalog or tutorial.

## What Changes

- Replace the four-card capabilities grid with a centered heading and a two-column composition: a truthful five-level visual and three short value messages.
- Use the existing Carobra typography and palette, with recognizable level colors, a light background and subtle elevation.
- Keep a single section action, “Quiero ser parte”, pointing to registration, and preserve the `#beneficios` anchor and subsequent how-it-works section.
- Stack the layout on mobile without a carousel, fabricated balances, personalized progress, or new API calls.

## Capabilities

### New Capabilities

- `landing-rewards-value`: Compact, accessible public explanation of Rewards value and its levels.

### Modified Capabilities

None.

## Impact

Frontend landing component, route composition and focused browser tests. No backend, authorization, rewards rules, production data, dependencies, commit or deployment changes.
